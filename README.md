# 💬 LAN Chat

사내 LAN 환경에서 동작하는 P2P 채팅 애플리케이션입니다.
별도 서버 없이 같은 로컬 네트워크의 사용자와 직접 연결해 채팅하고 파일을 공유합니다.

## ✨ 주요 기능

### 🌱 랜펫 (Lanpet)

채팅과 함께 돌보는 독자 가상 펫입니다. 상단의 **랜펫** 버튼에서 시작하며, 펫 생성과 다른 피어에게 공개하는 선택을 분리했습니다.

- 평일 **09:00–18:00**에 돌봄·성장·친구 활동을 할 수 있습니다. 밤과 주말은 무벌점 휴식입니다.
- 돌봄과 놀이, 선택형 3단계 성장, 친구 방문·협동 놀이·기념품·5턴 친선 배틀을 제공합니다.
- 배틀은 양측 수락 후 동등한 조건으로 진행하며 순위·약탈·연승 보상이 없습니다.
- 펫 정보와 교류 기록은 로컬 암호화 DB에 저장합니다. 채팅 본문·메시지 수를 성장에 사용하지 않고, 펫 OS 알림도 보내지 않습니다.
- 활동별 수신 허용과 피어 초대 차단을 설정할 수 있습니다. 결과 전달이 끊기면 확인 대기 상태로 표시하고 재연결 때 복구합니다.
- 교류하려면 **양쪽 앱이 v0.13.0 이상**이고 공개가 켜져 있어야 합니다. 구버전과의 기존 채팅은 유지됩니다.

### 🌐 네트워킹

| 기능 | 설명 |
|------|------|
| **자동 사용자 발견** | 같은 LAN의 사용자를 자동으로 찾아 연결 — IP 설정 불필요 |
| **전체 채팅** | 연결된 모든 피어에게 실시간 브로드캐스트 메시지 전송 |

| **오프라인 메시지 큐** | 상대방 오프라인 시 메시지를 보관 후 접속 시 자동 전달 |

## 사용 방법

1. 앱을 처음 실행하면 **닉네임, 아이디, 비밀번호** 설정 화면이 표시됩니다.
2. 같은 LAN에 있는 다른 PC에서 앱을 실행하면 자동으로 사이드바에 표시됩니다.
3. **전체 채팅** — `# 전체 채팅` 선택 후 메시지 입력
4. **DM** — 사이드바에서 상대방 이름 클릭 → 암호화된 1:1 채팅

## 주의사항

- **mDNS 방화벽**: Windows 첫 실행 시 방화벽 허용 팝업 승인이 필요합니다 (UDP 5353).
- **파일 URL 만료**: 발신자가 앱을 종료하면 전송한 이미지/영상에 접근할 수 없습니다.
- **기록 백업**: PC 포맷 후에도 DM 기록을 이어보려면 앱 데이터 폴더 전체를 백업하고, 기존 로그인 비밀번호를 사용해야 합니다. 일부 파일만 백업하면 복원할 수 없습니다. 데이터 폴더는 Windows의 `%APPDATA%/lan-chat`, macOS의 `~/Library/Application Support/lan-chat`에 있습니다.
