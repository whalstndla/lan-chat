# 랜펫 입체 놀이방 · v0.15.0

2026-09-08. 이 문서의 경주·초대 제한·입체 화면 규칙이 v0.14.0 설계보다 우선한다. 펫 시드, 6종과 18개 진화 형태, 계정의 코인·먹이·장식, 평일 09–18시 정책은 이어진다.

## 입체 화면과 연출

Three.js 0.185.1을 앱에 포함한다. 외부 모델·텍스처·CDN 요청 없이 로컬 도형으로 여섯 종의 몸, 귀·꼬리·부리, 진화 장식을 만든다. 기존 모달, 친구 화면, 성장 도감, 상점과 채팅 하단 놀이방에 적용한다. 방의 벽·바닥·가구도 입체 모델이다.

- 방: 걷기·숨쉬기·휴식 자세, 친구가 함께 돌아다니는 장면.
- 돌봄·급식·성장·꾸미기: 점프 반응, 퍼지는 빛과 별가루.
- 교류·배틀: 두 펫의 동작, 반짝이는 빛과 라운드 결과 연출.
- 경주: 실제 주사위 회전, 결과 확정 후 트랙 이동, 마지막 결과 안내.
- 기억 놀이: 1.1초 동안 입체 간식과 이름을 보여 주고, 세 카드에서 고른다. 정답과 오답을 설명한다.
- 복권: 코인 당첨 알림과 카드 강조. 사운드 재생은 하지 않는다.

활성 장면은 최대 초당 30프레임, 픽셀 비율은 최대 1.5로 제한한다. 화면 밖 또는 숨겨진 창은 렌더링을 멈춘다. 움직임 줄이기 설정에서는 이동 결과를 즉시 보여 주고 반복 동작·파티클을 끈다. 작은 프로필 이미지는 한 개의 공유 렌더러로 생성하고 캐시한다. 닫을 때 도형·재질·텍스처·렌더러를 해제한다. 게임 종류 변경과 재시도는 새 캔버스를 사용한다. 그래픽 초기화 실패 시 설명과 다시 열기 버튼을 표시하며 게임 결과·돌봄 버튼은 계속 동작한다.

구현 참고: [Three.js 장면 구성](https://threejs.org/manual/en/creating-a-scene.html), [GPU 자원 정리](https://threejs.org/manual/en/cleanup.html), [WebGLRenderer](https://threejs.org/docs/pages/WebGLRenderer.html).

## 주사위 경주

| 항목 | 친구 경주 | 혼자 경주 |
| --- | --- | --- |
| 규칙 | 두 소유자 수락 후 5턴 | 연습 친구와 5턴 |
| 진행 | 매턴 굴리기 버튼, 1~6칸 동일 확률 | 매턴 굴리기 버튼, 1~6칸 동일 확률 |
| 시간 | 매턴 15초, 미입력 시 자동 굴림 | 총 60초, 미완주 시 종료 |
| 판정 | 5턴 합계 거리, 같으면 무승부 | 5턴 합계 거리 비교 |
| 생성 | 주최 측 메인 프로세스가 두 주사위를 각각 생성 | 로컬 메인 프로세스가 생성 |
| 정합성 | 라운드·주사위·점수를 암호화 DB에 함께 저장, 상대는 범위·입력·합계를 검증 | 게임 ID·턴·요청 ID와 최소 입력 간격 검증 |
| 비용·보상 | 에너지 6, 교류 코인 한도 적용 | 완주 10코인 + 이동 3칸당 1코인, 최대 20 |

화면은 숫자를 보내지 않고 `roll` 요청만 보낸다. 중복 요청·재시작으로 같은 턴을 다시 굴리거나 보상을 중복 지급하지 않는다. 주최 기기의 앱이 주사위를 확정하는 친선 게임이며, 수정된 상대 앱의 난수 공정성을 상호 증명하는 방식은 아니다. 현금·환전·베팅은 없다.

새 경주는 `lanpet-dice-v1` 기능 협상과 세션 규칙 버전 2를 사용한다. 양쪽 v0.15.0 이상이 필요하다. 기존 채팅과 방문·함께 놀기·배틀·선물은 유지한다. 이전 진행 중 경주는 종료 후 새로 시작하도록 안내한다. 기존 코인과 진화 상태는 변경하지 않는다. 기존 선택형 경주의 마지막 화면은 새 주사위 기록으로 오인하지 않도록 보관 안내로 대체한다.

## 검증

새 주사위 범위·5턴 합계·자동 굴림·중복 요청·재초대 경계와 구버전 10분 정책을 검사한다. 실제 Electron 두 프로세스에서 시간 조작 없이 경주와 함께 놀기를 연속 완료하고, 입체 장면 전환·상점·기억 놀이·창 확장·200% 확대를 실행한다.

한 Mac의 두 프로세스와 루프백 소켓을 사용하므로 물리 PC 두 대의 mDNS 발견 검증과 구분한다. [실제 실행 기록](lanpet-three-qa/electron-report.json)을 확인한다. Apple 공증과 실제 설치된 구버전 자동 업데이트 실행은 이 검증에 포함하지 않는다.
