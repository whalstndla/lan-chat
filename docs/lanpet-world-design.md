# 랜펫 놀이방 · v0.14.0 상세 설계

2026-09-08. 기존 랜펫의 성장 선택·화면·경제 관련 내용을 이 문서로 갱신한다. 평일 09–18시, LAN 전용 통신, 명시적 펫 공개, 암호화 저장, 사망·강탈 없는 정책은 유지한다.

## 1. 화면 방향

사용자가 제공한 다마고치 원더샵 화면의 밝은 실내 공간, 둥근 장난감 같은 캐릭터, 커튼과 카펫을 참고한다. 랜펫은 독자적인 여섯 캐릭터와 SVG 그래픽을 사용한다. 기존 모달까지 동일한 바닐라·딸기 우유·소다 색상으로 바꾸며 채팅 화면의 테마는 유지한다. 외부 이미지 다운로드·폰트·서버가 필요 없다.

- **내 펫:** 꾸민 방, 현재 상태, 무료 돌봄, 성장 나무, 여섯 종 도감.
- **친구:** 기존 방문·협동·기념품·배틀과 신규 경주. 초대·수락·취소·재연결·결과 확인을 같은 흐름으로 제공.
- **상점·꾸미기:** 잔액, 먹이 구매·섭취, 소유한 벽지·바닥·가구 배치, 실시간 방 미리보기.
- **놀이터:** 혼자 하는 장애물 경주와 간식 짝맞추기, 무료 복권, 코인 내역.
- **추억·설정:** 기존 기능을 유지. 함께 놀기 허용 설정은 친구 경주에도 적용한다.

## 2. 랜덤 생성과 18개 진화 형태

펫 최초 생성·기존 펫 이관 시 메인 프로세스에서 128비트 난수 시드를 만들고 영구 저장한다. SHA-256 시드 해시로 6종 중 하나를 선택한다. 새로고침·모달 재개방·앱 재시작은 종을 다시 뽑지 않는다. 기존 이름·수치·성장 단계는 보존하며 새로운 종의 외형을 부여한다.

| 기본 종 | 정성 경로 | 모험 경로 | 우정 경로 |
|---|---|---|---|
| 살구여우 | 꽃잎여우 | 번개여우 | 리본여우 |
| 솜토끼 | 정원토끼 | 달빛토끼 | 축제토끼 |
| 방울수달 | 산호수달 | 파도수달 | 진주수달 |
| 별고양이 | 찻잎고양이 | 혜성고양이 | 왕관고양이 |
| 구름새 | 꽃구름새 | 무지개새 | 노래구름새 |
| 젤리곰 | 꿀단지곰 | 모험곰 | 하트곰 |

기본 실루엣·색상에 정성의 꽃 장식, 모험의 번개 머리띠, 우정의 리본이 더해진다. 씨앗 → 새싹 → 최종 동반자 두 성장 단계를 거친다. 최종 성장 시 가장 높은 성향의 형태만 제안하며, 버튼으로 확정한다. 동점은 시드에 고정된 순서로 결정한다. 확정 후 경로는 변경하지 않는다.

| 경험 | 성향 점수 | 제한 |
|---|---|---|
| 돌보기·정리하기 | 정성 +1 | 기존 반복 행동 판정 적용 |
| 놀아주기 | 모험 +1 | 기존 반복 행동 판정 적용 |
| 주먹밥 / 열매 / 컵케이크 | 정성 / 모험 / 우정 +3 | 먹이 전체 5분 간격 |
| 무료 간식 | 정성 +3 | 먹이 간격과 별도로 1시간 간격 |
| 혼자 하는 미니게임 완주 | 모험 +3 | 두 게임 합계 24시간 5회 시작 |
| 친구 놀이 완료 | 우정 +2 | 24시간 최초 3회 보상 |

성향별 기록은 5분에 한 번만 증가하고 최대 999점이다. 기존 성장 점수·유대·업무시간 요구 조건을 함께 충족해야 한다. 먹이·코인만으로 즉시 최종 진화할 수 없다.

| 다음 단계 | 성장 점수 | 유대 | 누적 업무시간 |
|---|---:|---:|---:|
| 새싹 | 40 | 15 | 9시간 |
| 동반자 | 140 | 50 | 63시간 |

## 3. 채팅방 하단 놀이방

입력창 아래 화살표로 아코디언을 열고 닫는다. 가능한 범위에서 실제 앱 창 높이를 아래로 늘려 채팅 영역을 보존한다. 최대화·전체 화면·화면 아래 여유 부족 시 창 안에서 펼친다. 접을 때 확장 전 높이로 복원하되 사용자가 직접 바꾼 크기는 덮어쓰지 않는다. 200% 확대 시 실제 확장량도 배율을 반영하며 디스플레이 작업 영역을 넘지 않는다.

개인 채팅에서는 **현재 상대의 공개된 펫만**, 전체 채팅에서는 현재 사용 가능한 주변 펫 최대 3마리를 표시한다. 친구와 나란히 걸으며 노는 연출은 화면 안에서만 계산한다. 위치·채팅 내용·타이핑을 펫 프로토콜로 보내지 않는다. 실제 게임 시작은 반드시 초대와 수락이 필요하다. 미공개·오프라인·차단된 친구는 놀이방에 표시하지 않는다. 접으면 구독을 해제하고, 움직임 줄이기 설정에서는 걷기·눈 깜빡임을 멈춘다.

놀이방 안에서 간식, 상점·꾸미기, 미니게임 모달, 경주·협동 초대와 수락·행동 선택까지 가능하다.

## 4. 코인과 먹이

재화는 **반짝 코인**이며 현금 구매·환전·양도·베팅이 없다. 계정 최초 100코인과 주먹밥 3개를 제공한다. 펫 삭제·재생성으로 시작 보상과 이용 한도를 초기화하지 않는다. 지갑·가방·방·복권 및 게임 수령 이력은 계정에 남는다. 잔액·아이템·보상 처리는 암호화 DB의 한 트랜잭션 안에서 저장한다.

| 먹이 | 가격 | 돌봄 | 기분 | 에너지 |
|---|---:|---:|---:|---:|
| 동글 주먹밥 | 8 | +14 | +2 | +4 |
| 반짝 열매 | 12 | +8 | +8 | +8 |
| 우정 컵케이크 | 16 | +10 | +14 | +3 |
| 무료 간식 | 0 | +6 | +2 | +2 |

수치는 100을 넘지 않는다. 구입은 한 번에 1개, 먹이는 종류당 최대 99개다. 재고가 없으면 먹일 수 없고 잔액 부족이면 구입 전체를 취소한다. 펫이 쉬는 중이거나 업무시간 밖이면 새로운 구매·섭취·배치·게임·추첨을 하지 않는다. 기본 돌봄과 무료 간식으로 코인이 없어도 관리할 수 있다.

## 5. 꾸미기 카탈로그

| 공간 | 기본 제공 | 구매 항목 |
|---|---|---|
| 벽 | 바닐라 | 딸기 밀크 60 / 소다 하늘 60 |
| 바닥 | 비스킷 마루 | 피크닉 체크 75 / 캔디 카펫 75 |
| 가구 | 작은 화분 | 구름 소파 100 / 장난감 피아노 140 / 쿠션 성 180 |

슬롯마다 하나를 배치한다. 구매한 장식은 소모하지 않고 다시 배치할 수 있다. 중복 구매는 거부한다. 방 소유권과 배치는 내 기기에만 저장하며 친구에게 전체 소지품이나 잔액을 공개하지 않는다.

## 6. 게임과 복권

**장애물 경주:** 60초 안에 다섯 구간에서 표시된 안전한 길(왼쪽·가운데·오른쪽)을 고른다. 구간을 지날 때 펫이 결승선으로 이동한다.

**간식 짝맞추기:** 구간마다 약 1.1초 보여 주는 간식을 기억하고 세 가지 중 하나를 고른다. 역시 60초에 다섯 문제다. 결과는 메인 프로세스가 보관한 정답과 비교한다.

두 게임 합쳐 최근 24시간 5회 시작할 수 있고 중도 종료·만료도 도전에 포함한다. 완주 5코인과 정답당 3코인(최대 20)을 준다. 게임 ID·구간·선택값·종료 상태·입력 간격을 검증한다. 렌더러가 점수나 보상액을 지정할 수 없다. 미완주에는 보상이 없다.

**친구 경주:** 양측 수락 후 15초씩 세 구간. 달리기 > 점프 > 지름길 > 달리기 관계에 따라 기본 3칸에 이긴 선택은 2칸을 더 전진한다. 미선택은 쉬기 0칸이다. 총 이동 거리로 승패를 결정하며 동점 가능하다. 종이나 장식에 승률 이점을 주지 않는다. 에너지 6을 예약·정산하고, 확정된 결과는 재연결 후에도 한 번만 적용한다. 친구 활동(방문·협동·배틀·경주)의 처음 3회 완료에 각 12코인을 지급한다. 승패에 따라 재화를 빼앗지 않는다.

**무료 행운 복권:** 24시간마다 한 장, 10코인 60%, 20코인 30%, 50코인 9%, 100코인 1%. 구매·코인 차감 없이 최소 보상을 보장하고 확률을 버튼 옆에 표시한다. 메인 프로세스에서 추첨하고 같은 트랜잭션으로 마지막 추첨·당첨금·지갑을 확정한다. 응답 재전송으로 다시 추첨하지 않는다.

## 7. 저장·호환성·검증

- 암호화 SQLite 스키마 2에 단일 `lanpet_world` 상태를 추가한다. 기존 펫과 대화 테이블을 변경하지 않는다. 이관은 재실행 가능하며 초기 시드를 한 번만 생성한다.
- 기존 랜펫 `requestId` 중복 처리와 트랜잭션을 재사용한다. 코인 내역은 최근 50개 저장, 화면에 12개 표시한다. 게임 정답 목록·시드·지갑은 피어에게 보내지 않는다.
- 기존 메시지 프로토콜과 `lanpet-v1`은 유지한다. 경주는 양쪽 모두 `lanpet-world-v1`을 알리는 경우에만 광고·초대한다. 기존 버전에는 경주 활동을 보내지 않는다. **친구 경주는 양쪽 v0.14.0 이상이 필요하다.**
- 시간을 뒤로 바꾼 경우 마지막 경제 활동 시각과 펫 평가 시각보다 이전의 새 경제 명령을 거부한다. 로컬 기기의 관리자 조작까지 막는 중앙 서버 경제 시스템은 아니다.
- 실제 Electron 두 프로세스와 임시 암호화 계정·루프백 소켓으로 게임·상점·먹이·꾸미기·모달·아코디언을 검증한다. 물리 PC 두 대의 mDNS 검증과 Apple 공증은 별도 미수행 항목이다.

창 크기는 Electron의 [BrowserWindow](https://www.electronjs.org/docs/latest/api/browser-window)와 [screen](https://www.electronjs.org/docs/latest/api/screen) 메인 프로세스 API를 사용한다. [실제 앱 검증 기록](lanpet-qa/electron-report.json)과 [놀이방 화면](lanpet-qa/15-chat-drawer.png)을 함께 확인할 수 있다.
