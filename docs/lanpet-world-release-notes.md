# 랜펫 놀이방 업데이트

- 랜덤 시드로 생성되는 기본 펫 6종, 먹이·돌봄·놀이·교류에 따른 최종 진화 형태 18개를 추가했습니다.
- 다마고치 원더샵의 밝은 방과 둥근 장난감 분위기를 참고해 랜펫 고유 캐릭터와 기존 모달을 새롭게 디자인했습니다.
- 채팅방 하단 놀이방을 펼쳐 현재 대화 상대의 펫과 함께 노는 모습을 보고 간식·경주·협동 초대를 이용할 수 있습니다.
- 친구 경주, 혼자 하는 장애물 경주와 간식 짝맞추기, 무료 행운 복권으로 반짝 코인을 모을 수 있습니다.
- 먹이 3종과 벽지·바닥·가구 상점을 추가했습니다. 현금 구매·환전·베팅은 없습니다.

친구 경주는 **양쪽 v0.14.0 이상**이 필요합니다. 기존 채팅과 방문·협동·선물·배틀은 이전 랜펫 지원 버전과 호환됩니다. 기존 펫의 이름·수치·단계를 보존하고 새로운 종과 외형을 부여합니다.

평일 09–18시 활동, 기본 비공개, LAN 전용 펫 통신, 암호화 저장을 유지합니다. 코인과 구입한 아이템·방·보상 수령 한도는 펫을 다시 만들어도 계정에 남습니다.

검증: 전체 114개 테스트 묶음·975개 테스트 및 프로덕션 빌드 통과. 실제 Electron 두 프로세스에서 27개 검사 통과, 22개 화면 캡처 확인. 좁은 창과 200% 확대, 경주 동기화·보상·먹이·꾸미기·창 확장/복원을 포함합니다.

배포 파일은 macOS Apple Silicon용 Developer ID 서명 DMG·ZIP입니다. 기존 사용자 승인에 따라 Apple 공증 없이 배포하며 Gatekeeper 공증 승인은 받지 않았습니다. 물리 PC 두 대의 mDNS 발견 검증은 이번 실행에 포함하지 않았습니다.
