# 랜펫 입체 놀이방 · v0.15.0

랜펫의 모달과 채팅 하단 놀이방을 Three.js 기반 입체 장면으로 바꾸고, 친구 경주와 혼자 경주를 매턴 주사위를 굴리는 방식으로 개편했습니다. 완료한 놀이도 10분 동안 다시 초대할 수 없던 문제를 해결하고, 각 제한의 이유와 남은 시간을 화면에 표시합니다.

## 달라진 기능

- 여섯 종의 펫과 18개 진화 형태를 입체 캐릭터로 표현합니다. 펫과 친구가 함께 걷는 방, 상점의 가구, 성장 도감, 돌봄·급식·교류·배틀의 빛과 별 이펙트를 적용했습니다.
- 경주는 5턴입니다. 매턴 주사위로 1~6칸 전진하고 합계 거리를 비교합니다. 친구 경주는 15초 동안 입력하지 않으면 자동으로 굴립니다. 주사위 값은 메인 프로세스에서 생성하고 저장합니다.
- 혼자 경주와 기억 놀이에 입체 트랙·주사위 회전·이동·간식 연출을 추가했습니다. 혼자 경주는 완주 10코인에 이동 3칸당 1코인을 더해 최대 20코인을 지급합니다.
- 새 버전끼리는 놀이를 완료한 직후 다시 초대할 수 있습니다. 취소·거절·미완료 초대는 최초 초대 시점부터 30초를 기다립니다. 이전 버전 친구의 기존 10분 제한은 이유와 업데이트 안내를 함께 표시합니다.
- 급식 5분, 무료 간식 1시간, 같은 돌봄의 온전한 효과 30분, 무료 복권 24시간, 미니게임·교류 보상 한도를 설명합니다. 남은 시간과 다음 이용 시각을 보여 주고 에너지·공개 설정·업무시간 등 다른 원인도 안내합니다.
- 입체 화면은 보이지 않을 때 렌더링을 멈추고, 움직임 줄이기 설정을 따릅니다. 게임 전환 시 캔버스 재사용으로 그래픽 초기화가 실패하던 문제를 수정했습니다.

## 호환성

**친구 주사위 경주에는 양쪽 모두 v0.15.0 이상이 필요합니다.** 기존 채팅과 방문·같이 놀기·배틀·선물은 유지됩니다. 기존 펫 시드, 진화 상태, 코인과 소유 물품도 유지됩니다. 이전 선택형 경주의 진행 기록에는 종료 안내를 표시합니다.

평일 09–18시 정책과 최근 24시간 미니게임 시작 5회·교류 코인 보상 3회 제한은 유지됩니다. 교류 코인 한도를 채운 뒤에도 함께 놀 수 있습니다. 외부 모델·텍스처를 내려받지 않으며, 현금·환전·베팅은 없습니다.

## 검증

- 전체 테스트: 116개 묶음, 986개 통과. 프로덕션 렌더러 빌드 통과.
- 실제 Electron 두 프로세스: 29개 검사 통과. 연속 경주·같이 놀기, 양쪽 결과·보상 일치, 상점·급식·기억 놀이, 채팅 창 확장, 좁은 화면과 200% 확대를 실행했습니다. 서로 다른 화면 캡처 22개를 기록했습니다.
- 주사위 범위·5턴 합계·자동 굴림·중복 요청 방지, 새 버전 재초대와 구버전 10분 제한의 시간 경계를 검사했습니다.
- 재초대 실패는 통신 단절이나 요청 ID 재사용이 아니라 완료된 세션까지 포함하던 초대 제한으로 재현했습니다. 완료 후 시간을 건너뛰지 않고 다시 놀이를 완료하는 검사로 수정 결과를 확인했습니다.

macOS Apple Silicon용 Developer ID 서명 배포입니다. Apple 공증은 포함하지 않습니다. Electron 검사는 한 Mac의 루프백 연결을 사용했으며, 물리 PC 두 대의 mDNS 발견과 설치된 구버전에서의 자동 업데이트 실행은 검증하지 않았습니다.
